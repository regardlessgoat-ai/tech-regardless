Kissimmee sits next to the parks, so a Tuesday dinner service can seat a table from
São Paulo, a table from Osaka and a table from Montreal in the same hour. A paper menu in
English with no pictures means pointing, guessing and smaller orders. That is the problem
PicMenu was built for. The diner scans the code, the menu opens in their language with a
photo of every dish, and the order gets placed with confidence.

The owner side had to be just as simple, because a restaurant has nobody on staff to
babysit software. Everything is done from a phone between lunch and dinner: change a price,
swap a photo onto a dish, pick a different look for the menu. The sixteen looks are genuinely
different layouts, not recolours, and the list of valid looks lives in **one allowlist
enforced identically on the server and in the browser** so a menu can never save as nothing.

Translation covers thirty-five languages, cached so the same dish is never paid for twice,
with a food glossary so *carne asada* doesn't come back as "grilled meat." Every theme's font
stack ends in a shared fallback chain carrying Noto CJK and Noto Arabic, so a diner reading
Japanese never sees a page of empty boxes.

The games came from watching families wait. Fifteen of them run inside the menu itself,
from Tic Tac Toe and Connect Four for two people to Solitaire and a drawing pad for one,
so the kids are occupied and the table stays relaxed until the food arrives.
